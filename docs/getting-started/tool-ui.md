# Tool UI

Open the 3D Viewport sidebar with **N**, then select **REVO DNA**. Use the four buttons on the left to switch tabs.

![REVO DNA workflow tabs](../assets/images/REVO_DNA_UI.png){.doc-screenshot}

<p class="doc-caption">MetaHuman Tools, Conform and Textures</p>

## 1. MetaHuman Tools

Import DNA, conform by UVs, sculpt, check LODs and animation, then bake and export your character.

![MetaHuman Tools](../assets/images/tool_UI_metahuman_tools.png){.doc-screenshot .tool-ui-screenshot}

<p class="doc-caption">MetaHuman Tools</p>

## 2. Conform

Fit a head or body to a custom sculpt or scan using markers. Protect areas, preview the fit, then Apply or Create Object.

![Conform](../assets/images/tool_UI_Conform_tools.png){.doc-screenshot .tool-ui-screenshot}

<p class="doc-caption">Conform</p>

## 3. Textures

Transfer textures from the Target to the Source, extend texture borders and save the images.

![Textures](../assets/images/tool_UI_TextureTransfer_tools.png){.doc-screenshot .tool-ui-screenshot}

<p class="doc-caption">Textures</p>
